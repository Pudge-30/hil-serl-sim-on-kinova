# 手柄摇杆控制程序重写 - 8位无符号版本

## 重写说明

根据实际测试，手柄摇杆的取值均为 0-255（8位分辨率），已重写整个手柄控制程序，使用无符号归一化，确保：
1. 摇杆居中时，机械臂静止不动
2. 摇杆移动时，速度与摇杆角度呈线性关系

## 主要修改

### 1. 分辨率配置 ✅
- **修改前**：摇杆使用16位分辨率（2^16 = 65536）
- **修改后**：所有摇杆和扳机均使用8位分辨率（256，实际范围0-255）
- **位置**：`spacemouse_expert.py` 第157-165行

```python
resolution={
    'ABS_X': 256,       # 左摇杆 X 轴（8位，范围0-255）
    'ABS_Y': 256,       # 左摇杆 Y 轴（8位，范围0-255）
    'ABS_RX': 256,      # 右摇杆 X 轴（8位，范围0-255）
    'ABS_RY': 256,      # 右摇杆 Y 轴（8位，范围0-255）
    'ABS_Z': 256,       # 左扳机（8位，范围0-255）
    'ABS_RZ': 256,      # 右扳机（8位，范围0-255）
    'ABS_HAT0X': 1.0,   # D-pad X 轴
}
```

### 2. 归一化公式 ✅
- **公式**：`normalized = (raw_value - 127.5) / 127.5`
- **中心值**：127.5（8位范围[0, 255]的中点）
- **特性**：
  - 当 `raw_value = 127.5`（中心）时，`normalized = 0`，机械臂静止
  - 当 `raw_value = 0`（最小）时，`normalized = -1`
  - 当 `raw_value = 255`（最大）时，`normalized = 1`
  - **速度与摇杆角度呈线性关系**：`speed = normalized * scale`

### 3. 死区设置 ✅
- **死区阈值**：0.05 (5%)
- **作用**：当 `|normalized| < 0.05` 时，视为摇杆在中心位置
- **对应原始值范围**：raw_value 在 [121.125, 133.875] 范围内时被视为中心
- **效果**：确保摇杆居中时机械臂静止不动

### 4. 缩放因子（最大速度）✅
- **左摇杆**（ABS_X, ABS_Y）：-0.15（负号表示方向）
- **右摇杆**（ABS_RX, ABS_RY）：0.25（用于旋转）
- **扳机**（ABS_Z, ABS_RZ）：0.1
- **D-pad**（ABS_HAT0X）：0.3

### 5. 删除自动检测逻辑 ✅
- 删除了复杂的有符号/无符号自动检测逻辑
- 统一使用8位无符号归一化
- 简化了代码，提高了可靠性

### 6. 改进超时检查 ✅
- 超时检查时，不仅检查action值，还检查原始值是否在中心位置
- 如果原始值在中心位置（接近127.5），即使没有新事件，也重置action
- 确保摇杆回到中心时能及时停止

## 速度与角度线性关系

### 数学原理

对于8位无符号摇杆 [0, 255]：
- **中心值**：127.5
- **归一化公式**：`normalized = (raw_value - 127.5) / 127.5`
- **速度公式**：`speed = normalized * scale`

### 线性关系验证

| 摇杆位置 | raw_value | normalized | speed (scale=0.15) |
|---------|-----------|------------|-------------------|
| 中心     | 127.5     | 0.0        | 0.0（静止）        |
| 25%偏移  | 159.375   | 0.25       | 0.0375           |
| 50%偏移  | 191.25    | 0.5        | 0.075            |
| 75%偏移  | 223.125   | 0.75       | 0.1125           |
| 最大     | 255       | 1.0        | 0.15（最大速度）   |

**结论**：速度与摇杆偏移角度呈完美的线性关系。

## 摇杆居中检测

### 死区机制

- **死区阈值**：0.05 (5%)
- **原始值范围**：[121.125, 133.875]
- **检测逻辑**：
  ```python
  normalized = (raw_value - 127.5) / 127.5
  if abs(normalized) < 0.05:
      normalized = 0.0  # 视为中心，机械臂静止
  ```

### 超时检查机制

- **超时时间**：150ms
- **检查频率**：每100ms检查一次
- **检查逻辑**：
  1. 如果原始值在中心位置（接近127.5），重置action
  2. 如果action值不为0，重置action
  3. 确保摇杆回到中心时能及时停止

## 代码结构

### 主要函数

1. **`_read_joystick()`**：后台进程，持续读取手柄输入
   - 归一化处理
   - 死区处理
   - 速度计算
   - 超时检查

2. **`get_action()`**：获取最新的动作和按钮状态
   - 返回6DOF动作数组和按钮状态

### 动作映射

- `action[0]`：ABS_Y（左摇杆Y轴）→ Y轴平移
- `action[1]`：ABS_X（左摇杆X轴）→ X轴平移
- `action[2]`：ABS_RZ/ABS_Z（扳机）→ Z轴平移
- `action[3]`：ABS_RX（右摇杆X轴）→ Roll旋转
- `action[4]`：ABS_RY（右摇杆Y轴）→ Pitch旋转
- `action[5]`：ABS_HAT0X（D-pad）→ Yaw旋转
